# FrameSelector
Интерфейс предназначен для поиска области вокруг дрона по его предполагаемым координатам и предоставления ИИ-модели для дальнейшего анализа.
## GeoTiffFrameSelector
Реализация интерфейса FrameSelector, для работы с файлами в формате GeoTiff.
### Описание
GeoTiffFrameSelector строит индекс для ускорения выбора файлов по предполагаемой позиции дрона с помощью R-дерева.
Узел дерева представляет собой агрегированную область точек, на каждом из которых определяется, какой из потомков содержит в себе искомую точку.

В случае если точке соответствует несколько снимков, то выбирается наиболее эффективный. Наиболее эффективным считается тот,
1) расстояние от центра которого до предполагаемой позицией дрона будет наименьшим
2) у которого наименьший размер пикселя

Для вычисления размера вырезаемой области снимка высота дрона считается исчисляемой относительно уровня моря.

### Методика тестирования
В директории test_scripts содержатся скрипты 
1) generate_test_geotiffs.py - генерирует тестовые .tiff файлы, где положение дрона отмечено белой точкой и сохраняет их в указанную директорию.
Пример команды представлен ниже.
```bash
    python test_scripts/generate_test_geotiffs.py \
      --output-dir ./test_scripts/test_data \
      --grid-size 3 \
      --tile-size-m 1000 \
      --gsd 1.0 \
      --seed 42
```
2) frame_selector_test.py - создаёт тестовый GeoTiffFrameSelector с указанными параметрами и выполняет запрос для каждой белой точки (предполагаемой позиции дрона) на выделение области вокруг неё, после чего сохраняет её в файл в указанную директорию с тем же именем, что и исходный тестовый файл.
Тест считается пройденным успешно, если для всех тестовых файлов была вырезана область, содержащая белую точку.
Пример команды представлен ниже
```bash
python -m test_scripts.frame_selector_test \
      --data-dir ./test_scripts/test_data  \
      --output-dir ./test_scripts/crops \
      --source-crs EPSG:4326 \
      --target-crs EPSG:32632 \
      --fov-h 80 \
      --fov-v 60 \
      --crop-margin 1.0 \
      --altitude 100.0
```
